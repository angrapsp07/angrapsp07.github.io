Exclusão de Dados — TnC Financeiro

Atualização: 18 de outubro de 2026

O TnC Financeiro é um aplicativo para organização de finanças pessoais e empresariais, desenvolvido por Paulo Sérgio Palota.

O aplicativo não exige a criação de uma conta própria. A conexão com uma Conta Google é opcional e permite utilizar recursos de backup e restauração no Google Drive.

1. Como solicitar a exclusão dos dados

Os usuários podem entrar em contato com o responsável pelo aplicativo para solicitar orientações ou a exclusão de informações que estejam sob responsabilidade do desenvolvedor.

Desenvolvedor: Paulo Sérgio Palota

Aplicativo: TnC Financeiro

E-mail: suporte.tncfinanceiro@gmail.com

Solicitar exclusão de dados

Na solicitação, informe que utiliza o TnC Financeiro, quais informações deseja excluir e se utiliza o backup no Google Drive.

Não envie senhas, códigos de autenticação, números completos de cartões ou informações financeiras desnecessárias.

2. Exclusão de dados no dispositivo

O aplicativo permite registrar informações como receitas, despesas, saldos, cartões, investimentos, dados de perfil e registros de alunos e treinos.

Para apagar os dados locais no Android, o usuário pode acessar Configurações do dispositivo, Aplicativos, TnC Financeiro, Armazenamento e Limpar dados. Os nomes dessas opções podem variar conforme o aparelho.

Essa operação remove os dados locais do aplicativo. A limpeza de cache, isoladamente, não realiza a exclusão completa dos registros.

3. Exclusão de backups no Google Drive

Quando autorizado pelo usuário, o TnC Financeiro utiliza uma área privada do Google Drive para armazenar informações de backup.

Para verificar a possibilidade de excluir os dados ocultos do aplicativo, acesse o Google Drive pelo navegador, abra Configurações e depois Gerenciar aplicativos. Localize o TnC Financeiro e procure, no menu Opções, a função de exclusão dos dados ocultos do aplicativo, quando disponível.

Desconectar a Conta Google ou desinstalar o aplicativo do dispositivo não deve ser considerado, por si só, uma confirmação de exclusão dos backups existentes.

Caso não encontre a opção de exclusão, entre em contato com o suporte para receber orientações sobre os controles disponíveis.

Atenção: A exclusão dos dados locais ou dos backups pode ser permanente e impedir a recuperação das informações financeiras.

4. Dados excluídos e dados mantidos

A limpeza dos dados do aplicativo pode remover os registros financeiros, dados de perfil, cartões, investimentos, configurações e informações do Personal Trainer armazenados naquele dispositivo.

Backups na Conta Google permanecem sob os controles de armazenamento dessa conta até que sejam removidos. Arquivos exportados manualmente também precisam ser excluídos dos locais onde foram salvos pelo usuário.

Solicitações enviadas ao suporte serão analisadas conforme os dados e recursos envolvidos. Eventuais registros de atendimento poderão ser conservados pelo período necessário para responder à solicitação ou cumprir obrigações legais aplicáveis.

5. Privacidade e atendimento

Para conhecer as práticas de utilização e proteção de informações, consulte nossa Política de Privacidade.

Dúvidas e solicitações podem ser enviadas para suporte.tncfinanceiro@gmail.com .
